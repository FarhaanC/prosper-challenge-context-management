**Why "someone else" kept breaking (the root cause).** Rounds 2, 3 and 4 all found bugs in the same place: the code was trying to understand the caller's sentence ("someone else, please", "no, not Dr. Chen", "any language"). That breaks the plan's own rule, decision 23: *the AI understands speech; the code follows instructions and checks them*. Every new phrase was a new bug, and a Prosper engineer would find one in seconds. So instead of adding more phrases, Farhaan chose to stop the code reading phrases at all.
